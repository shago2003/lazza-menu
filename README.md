# Lazza — QR-меню кафе

Сайт-меню для кафе в Баку: гость сканирует QR на столике, открывает меню на своём
языке, собирает заказ в корзину и одним нажатием отправляет его вам в WhatsApp.
Там же можно оставить отзыв.

Три языка — азербайджанский, русский, английский. Цены в манатах.
Сайт рассчитан в первую очередь на смартфон, но открывается и на компьютере.

Работает без сервера и базы данных — это обычные файлы, которые можно положить
на любой хостинг.

## Что внутри

| Файл | Зачем нужен |
|---|---|
| `index.html` | Сама страница меню |
| `menu.js` | **Настройки кафе и меню — главный файл, который вы правите** |
| `i18n.js` | Надписи интерфейса на трёх языках |
| `styles.css` | Оформление, обе темы |
| `app.js` | Корзина, заказ, отзывы, переключение языков |
| `ar.js` | Просмотр блюда в 3D и «поставить на стол» через камеру |
| `models/` | 3D-модели блюд (.glb) |
| `vendor/` | Движок 3D от Google — лежит локально, чтобы сайт ни от кого не зависел |
| `tools/` | Сборка 3D-моделей и приёмка сканов с телефона |
| `qr.html` | Генератор табличек с QR-кодами для столиков |
| `images/` | Фотографии блюд |
| `artifact.html` | Тот же сайт, целиком в одном файле — удобно переслать или залить одним куском |

## Первым делом: впишите свой номер WhatsApp

Откройте `menu.js` в любом текстовом редакторе (подойдёт Блокнот) и замените номер:

```js
whatsapp: '994501234567',
```

Только цифры, с кодом страны, без `+`, пробелов и скобок.
Для Азербайджана это `994` плюс номер без начального нуля.
Пример для +994 (55) 123-45-67 → `994551234567`.

Пока номер не заменён, сайт работает в демо-режиме и предупреждает об этом при отправке.

Там же, рядом, задайте остальное:

```js
phone: '+994 50 123 45 67',   // показывается в шапке, по нажатию звонит
instagram: 'lazza.cafe',      // ник без «@», по нажатию открывает профиль

address: {
  az: 'Heydər Əliyev küçəsi, 12',
  ru: 'Ул. Гейдара Алиева, 12',
  en: 'Heydar Aliyev street, 12',
},
city: { az: 'Bakı', ru: 'Баку', en: 'Baku' },

openFrom: 9,             // час открытия — по нему считается индикатор «Открыто»
openTo: 23,              // час закрытия
mapUrl: '...',           // ссылка на карту, открывается по нажатию на адрес

currency: '₼',
deliveryFee: 5,          // стоимость доставки
freeDeliveryFrom: 40,    // бесплатно от этой суммы
minOrder: 15,            // минимальная сумма заказа на доставку

defaultLang: 'az',       // язык, если у гостя редкий язык браузера
```

Телефон и Instagram гость видит сразу на первом экране, крупными кнопками.

## Языки

Гость переключает язык кнопками **AZ / RU / EN** в правом верхнем углу шапки —
там, где их обычно и ищут. Те же кнопки продублированы в подвале, чтобы не
пролистывать страницу обратно наверх. Выбор запоминается до следующего визита.

При первом заходе язык определяется автоматически по настройкам браузера,
а если язык незнакомый — берётся `defaultLang` из `menu.js`.
Ссылка вида `index.html?lang=ru` открывает меню сразу на нужном языке и
перебивает сохранённый выбор — удобно для отдельного QR-кода на другом языке.

Переключение переводит всё: категории, названия блюд, добавки, чек, подсказки
и даже сообщение, которое уходит вам в WhatsApp.

- **Надписи интерфейса** (кнопки, ошибки, подсказки) — в `i18n.js`.
- **Меню** (названия и описания блюд) — в `menu.js`, у каждой позиции три языка.

### Убрать или добавить язык

Чтобы оставить только два языка, удалите ненужную строку из списка в начале `i18n.js`:

```js
const LANGS = [
  { code: 'az', label: 'AZ', name: 'Azərbaycan', dec: ',', grp: '.' },
  { code: 'ru', label: 'RU', name: 'Русский',    dec: ',', grp: ' ' },
  { code: 'en', label: 'EN', name: 'English',    dec: '.', grp: ',' },
];
```

`dec` — десятичный разделитель, `grp` — разделитель тысяч: с ними цена выглядит
как `9,90 ₼` или `1.234,50 ₼`.

Чтобы добавить, скажем, турецкий, допишите сюда строку с `code: 'tr'`, а затем
скопируйте блок `en: { … }` в `i18n.js` под именем `tr` и переведите. Позициям меню
тоже понадобится поле `tr` — где перевода нет, подставится язык из `defaultLang`.

## Светлая и тёмная тема

Кнопка с солнцем или луной стоит слева от переключателя языков — и в шапке,
и в подвале. Выбор гостя запоминается до следующего визита.

Тема по умолчанию задаётся в `menu.js`:

```js
defaultTheme: 'dark',   // 'dark' — фирменная тёмная, 'light' — светлая,
                        // 'auto' — как настроен телефон гостя
```

Сейчас стоит `dark`: тёмный фон выгоднее показывает фотографии еды и приятнее
вечером в зале. `auto` имеет смысл, если у вас летняя терраса — днём на ярком
солнце светлая тема читается лучше, и телефон гостя переключит её сам.

Шапка с фотографией остаётся тёмной в обеих темах — светлый текст на снимке
читается лучше, чем любой другой вариант. Чек в корзине, наоборот, в обеих
темах бумажный: это его смысл.

## Как изменить меню

Всё меню — список `MENU` в `menu.js`. Одна позиция выглядит так:

```js
{
  id: 'b1',                          // уникальный код позиции, не повторяйте
  price: 9.90,                       // цена в манатах
  img: 'images/burger-classic.jpg',
  weight: { v: 240, u: 'g' },        // u: 'g' — граммы, 'ml' — мл, 'pcs' — штуки, 'kg' — кг
  kcal: 620,
  tag: 'hit',                        // необязательно: 'hit', 'new', 'deal'
  name: { az: 'Lazza Classic', ru: 'Lazza Classic', en: 'Lazza Classic' },
  desc: {
    az: 'Kömürdə bişmiş mal əti kotleti, çedder…',
    ru: 'Котлета из говядины на углях, чеддер…',
    en: 'Charcoal-grilled beef patty, cheddar…',
  },
  mods: [MODS.burgerExtras],         // необязательно: добавки и размеры
}
```

- **Изменить цену** — поменяйте число в `price`. Точка, не запятая: `9.90`.
- **Убрать позицию** — удалите её блок целиком, вместе с фигурными скобками и запятой.
- **Добавить позицию** — скопируйте соседний блок и поправьте поля. Проследите, чтобы `id` не повторялся.
- **Пометка `tag`** делает карточку крупной, с большим фото. Не ставьте её всем подряд — она работает как раз потому, что таких позиций мало.
- **Целая категория** — блок в `MENU` с `id`, `title`, `note` и списком `items`.

### Добавки и размеры

Готовые наборы лежат в начале `menu.js` в объекте `MODS`: добавки к бургерам,
размер порции, объём стакана, вид молока, сиропы. Их можно переиспользовать
у любой позиции или задать свои прямо в позиции:

```js
mods: [{
  id: 'sauce', type: 'single', required: true,
  title: { az: 'Sous', ru: 'Соус', en: 'Sauce' },
  choices: [
    { price: 0,    name: { az: 'Turş-şirin', ru: 'Кисло-сладкий', en: 'Sweet & sour' } },
    { price: 0.50, name: { az: 'Pendirli',   ru: 'Сырный',        en: 'Cheese' } },
  ],
}]
```

`type: 'single'` — выбрать один вариант, `type: 'multi'` — можно несколько.
Цена добавки прибавляется к цене позиции.

## Где гость пишет отзыв

Внизу страницы есть раздел **«Что о нас говорят»** — там средняя оценка, отзывы
и кнопка «Написать отзыв». Попасть туда можно двумя способами: пролистать меню
до конца или нажать **«Отзывы»** — последний пункт в строке категорий наверху.

Кнопка открывает форму: оценка звёздами, имя и текст. После отправки отзыв
уходит вам в WhatsApp и сразу появляется на странице.

### Что важно понимать про отзывы

Отзыв приходит вам в WhatsApp — его вы получите обязательно.

На самой странице отзыв сохраняется только в браузере того гостя, который его
написал: другие посетители его не увидят. Так работает сайт без базы данных.
Отзывы в разделе — это список `SEED_REVIEWS` в конце `menu.js`, и пополняете его
вы: получили хороший отзыв в WhatsApp — добавьте его туда руками, на трёх языках.

```js
const SEED_REVIEWS = [
  {
    name: 'Aysel', rating: 5, date: '2026-08-24',
    text: { az: 'Kapuçino əladır…', ru: 'Капучино отличный…', en: 'Great cappuccino…' },
  },
];
```

Если понадобится, чтобы отзывы появлялись на сайте сами и у всех, нужен бэкенд —
подойдут Google-таблица через Apps Script, Supabase или Firebase.

## Как заменить фотографии

Сейчас в `images/` лежат бесплатные фото с Unsplash — это заглушки, чтобы
меню выглядело живым. **Замените их на снимки своих блюд** — это заметно
повышает заказы, и гость получает то, что видел.

1. Сфотографируйте блюдо сверху или под углом 45°, на однотонном фоне.
2. Обрежьте до пропорций 4:3 и уменьшите до ширины ~700 пикселей.
3. Сохраните в `images/` под тем же именем, что и старый файл, — тогда ничего
   менять в коде не нужно. Либо укажите новое имя в поле `img`.

## 3D-меню и «поставить на стол»

У каждой позиции есть кнопка **«Смотреть в 3D»**: фото сменяется моделью,
которую можно покрутить пальцем. Дальше — **«Поставить на стол»**, и вот тут
два режима. Приложений гостю ставить не нужно ни в одном.

**Быстрый — он открывается по умолчанию.** Включается камера телефона, блюдо
появляется поверх картинки сразу, ждать нечего. Гость сам наводит его на своё
место за столом, двумя пальцами меняет размер. Блюдо не приклеено к столу —
двигается вместе с экраном, зато показывается мгновенно. Размер прикидочный,
в духе «примерно такая порция».

**Точный — кнопка «Закрепить на столе» уже внутри камеры.** Это настоящий AR:
Scene Viewer на Android, AR Quick Look на iPhone. Блюдо встаёт на стол
в натуральную величину и остаётся на месте, когда обходишь его вокруг. Цена —
несколько секунд: телефон просит поводить камерой, пока не найдёт плоскость.
**Это ожидание отключить нельзя** — оно внутри ARCore и ARKit, сайт ими не
управляет. Поэтому первым и открывается быстрый режим, а точный остаётся
для тех, кому нужна честная привязка к столу.

Что где работает:

* **Быстрый режим** — любой телефон, чей браузер умеет камеру; доступ гость
  разрешает один раз.
* **Точный режим, Android** — Google Scene Viewer (нужны «Google Play Услуги
  для AR», на большинстве телефонов уже стоят).
* **Точный режим, iPhone / iPad** — AR Quick Look в Safari, начиная с iOS 12.
* **Компьютер** — камеры нет, но модель крутится на экране; гость видит
  подсказку открыть меню с телефона.

Обязательное условие — сайт по `https://`. У нас он такой.

Модель весит 20–300 КБ и **загружается только когда гость сам нажал кнопку**,
так что на скорость открытия меню это не влияет.

### Как снять настоящее блюдо и поставить его вместо стилизованного

Модели в `models/` — заглушки: узнаваемые, но это не ваша котлета. Настоящую
модель снимают телефоном за пять минут, никакого оборудования не нужно.

**Приложение.** [Scaniverse](https://scaniverse.com) от Niantic — бесплатное,
без ограничений по числу сканов, есть под iPhone и Android. Запасные варианты —
RealityScan от Epic Games и KIRI Engine.

**Съёмка выглядит как видео — так и должно быть.** Приложение набирает кадры
с разных сторон, а трёхмерную модель считает уже после, когда вы нажмёте
«Process». Объём берётся из того, что один и тот же кусок блюда попал в кадр
с разных точек. Поэтому важно именно обойти блюдо, а не снять его с одного места.

**Главная ловушка: меш или сплат.** Scaniverse по умолчанию делает
*гауссов сплат* — красивую «облачную» модель для просмотра. Она выглядит
эффектнее меша, но это не набор треугольников: её нельзя выгрузить в OBJ,
и ни сайт, ни AR её не покажут. Перед съёмкой выберите режим **Mesh**
(в справке Scaniverse так и написано: меш нужен, если модель уходит
в стороннюю программу). Если получился сплат — переснимите, конвертировать
его в меш приложение не умеет.

**Как снимать — от этого зависит всё.** Модель получится ровно такой, как съёмка:

1. Поставьте блюдо на матовую однотонную поверхность: деревянная доска,
   бумажная салфетка, крафтовый лист. Стекло, зеркало и глянец сканер не видит.
2. Свет ровный и рассеянный. Лучше всего днём у окна. Одна яркая лампа даёт
   резкую тень, и она «впечатается» в модель.
3. Блюдо не двигаем — ходим вокруг сами. Три круга: на уровне стола, под 45°
   и почти сверху. Всего 40–80 кадров.
4. Двигайтесь плавно и держите блюдо целиком в кадре. Не крутитесь на месте:
   нужно именно обойти вокруг.
5. В приложении обрежьте лишнее — стол, руки, фон. Экспорт: **OBJ**,
   детализация средняя. Именно OBJ: его отдают все сканеры, а GLB есть
   не везде (в справке Scaniverse для мешей указаны OBJ, FBX и USDZ).
   Высокая детализация даст файл на десятки мегабайт, гость его не дождётся.
   Рядом с `.obj` приложение положит `.mtl` и картинку-текстуру —
   держите эти файлы вместе, они нужны все.

**Что снимается плохо.** Прозрачное и блестящее: стаканы, лимонад, кола, лёд,
глянцевый соус. Сканер видит стекло как пустоту или как мутный ком. Для напитков
честнее оставить стилизованные модели, а сканировать то, что матовое и объёмное:
бургеры, фри, десерты, выпечку.

**Дальше одна команда.** Скопируйте файл с телефона на компьютер и запустите
из папки сайта:

```
python tools/prepare_scan.py scan.obj burger-classic
```

Принимаются `.obj` (вместе с `.mtl` и текстурой рядом) и `.glb`.
Вместо `scan.obj` — путь к вашему файлу. В PowerShell можно просто перетащить
файл мышкой в окно терминала, путь подставится сам. Второй параметр — имя
позиции, как в `menu.js`: `burger-classic`, `fries-classic` и так далее.

Команда сама:

* **почистит скан** — выбросит плиту стола, обрывки в воздухе и мелкий мусор.
  Это тот самый этап, который в студиях AR-меню делают вручную в 3D-редакторе,
  и именно из-за него необработанный скан выглядит кривым. Заодно чистка чинит
  масштаб: пока в модели лежит кусок стола, размер считается по столу, и блюдо
  выходит в разы мельче, чем надо;
* поставит блюдо на «пол» и выровняет по центру;
* приведёт к натуральной величине — по умолчанию под размер той модели, что
  сейчас лежит в `models/`, либо укажите своё: `--size 12` (сантиметры);
* ужмёт текстуры до 2048 пикселей, чтобы файл грузился на мобильном интернете;
* сохранит прежнюю модель рядом как `.bak` — если результат не понравится,
  просто верните её обратно;
* скажет, сколько получилось, и предупредит, если файл всё ещё тяжёлый.

Если чистка сработала не так, ей можно помочь:

* `--dirty` — не чистить вообще, посмотреть, что вышло из сканера;
* `--floor off` — не срезать низ (если блюдо стоит на тарелке и её жалко);
* `--floor 15` — срезать нижние 15% высоты вручную;
* `--radius 70` — оставить только центр, отрезав стол по кругу;
* `--speck 5` — строже выбрасывать мелкие куски.

Остальные ключи: `--dry` (посмотреть, ничего не записывая), `--rot-y 90`
(довернуть блюдо), `--rot-x -8` (поправить наклон), `--zup` (блюдо лежит
на боку — бывает, когда сканер считает «верхом» ось Z), `--tex 1024`
(текстуры полегче), `--keep` (не трогать текстуры вовсе).

**Проверьте результат.** `python tools/preview.py burger-classic` покажет
картинку, не открывая браузер. Потом откройте сайт и нажмите «Смотреть в 3D».
Если всё хорошо — `git push`, и через минуту это у гостей.

Ориентиры по весу: 3–5 МБ на блюдо — нормально, больше 6 МБ гость на мобильном
интернете будет ждать. Треугольников больше 150 тысяч — выгрузите скан заново
с меньшей детализацией. Файлы `.usdz` для айфонов делать не нужно, сайт готовит их
сам на лету.

### Как убрать 3D

* У одной позиции — удалите в `menu.js` строку `model: 'models/...glb'`.
  Кнопка у этого блюда просто не появится.
* Совсем везде — удалите строку `<script src="ar.js"></script>` из `index.html`.

### Откуда взялись готовые модели

Их собирает скрипт `tools/make_models.py` — из простых фигур, по описанию
каждого блюда. Пересобрать все модели: `python tools/make_models.py`.
Посмотреть, что получилось, не открывая браузер: `python tools/preview.py`.
Владельцу кафе это не нужно — только если захотите поменять, скажем, цвет
булки у всех бургеров сразу.

## Как опубликовать

Сайту не нужен сервер с базой — достаточно любого статического хостинга.
Самый быстрый способ:

1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите туда всю папку целиком.
3. Через несколько секунд получите адрес вида `https://ваше-имя.netlify.app`.

Так же работают GitHub Pages, Vercel, Cloudflare Pages или обычный хостинг по FTP.
Главное — сохранить структуру папки: `index.html` в корне, рядом `menu.js`,
`i18n.js`, `app.js`, `styles.css` и папка `images/`.

Проверить локально можно и без хостинга — просто откройте `index.html` двойным
щелчком, всё работает.

## Как сделать QR-коды для столиков

Откройте `qr.html`, вставьте адрес опубликованного меню, укажите число столиков
и нажмите «Собрать таблички», затем «Распечатать».

Каждая табличка ведёт на адрес вида `?table=7`. Гость, отсканировавший код
на седьмом столике, сразу получит меню с уже выбранным способом «за столик»
и номером 7 — ему останется только собрать заказ. Подписи на табличках — на трёх
языках, как и меню.

Печатайте на плотной бумаге, сгибайте по пунктиру. Перед тем как разложить
таблички по залу, проверьте камерой хотя бы несколько кодов.

Гость отправляет сообщение сам — то есть заказ приходит с его номера,
и вы сразу можете ответить в том же чате.

**Заказ не считается принятым, пока вы не ответили.** Напишите подтверждение
и время готовности — гость этого ждёт.

## Мелочи, о которых стоит знать

- Корзина сохраняется в браузере гостя: если он случайно закроет страницу, заказ не потеряется.
- Смена языка не сбрасывает корзину — позиции просто переводятся.
- Индикатор «Открыто / Закрыто» считается по часам `openFrom` и `openTo` на устройстве гостя.
- Кафе закрыто — заказ всё равно можно отправить, но гость увидит подсказку, что примете вы его к открытию.
- Поля формы набраны шрифтом в 16 пикселей: iPhone иначе увеличивает страницу при вводе.
- Цвета собраны в переменные в начале `styles.css`: блок `:root` — тёмная тема, `:root[data-skin='light']` — светлая. Меняете пару значений — меняется вся страница.
- Переход по категории на дальнее расстояние происходит мгновенно, на близкое — плавно. Плавная прокрутка через всё меню длилась бы несколько секунд, и казалось бы, что нажатие не сработало.
- Шрифты подгружаются из Google Fonts. Без интернета сайт откроется системным шрифтом, вёрстка не поедет.
- Оплата на сайте не принимается: гость платит на кассе, официанту или курьеру.
